JMC Sheet Maker: JMC sketch DWG to PDF at true scale for land acquisition

JMC Sheet Maker is free Windows software that turns your JMC sketch (joint measurement certificate) DWGs for land acquisition into DWG to PDF at true scale: A3 sheets from Model space at 1:500, 1:1000 or 1:2000 (A2, A1 or A0 when the sketch is bigger), and one bookmarked PDF per village with the pages in survey / hissa order.

Features

From JMC sketch DWGs to print-ready, true-scale PDFs

Point it at the folder of JMC sketch DWGs for a job, pick an option, and get sheet DWGs, one PDF per village and a sheet list, without touching your drawings.

Make true-scale sheets from Model space

  • One folder per job; about 1 minute per village per option
  • Option D: every sheet at 1:1000 on A3, portrait or landscape per sheet so the hatched LA portion fits
  • Option E: one scale you type as metres per cm (10 = 1:1000, 5 = 1:500, 20 = 1:2000), paper A3 / A2 / A1 / A0 per sheet
  • Options A, B and C: A3 paper-space layouts, border scaled in Model space, or all at 1:1000 with the view kept on the LA hatch
  • Old notes like “1 Cm = 16 Mtr” are corrected to the real scale

One bookmarked PDF per village

  • Pages in survey / hissa order (5/1, 5/2 … 70/10), bookmarked by survey number
  • Plotted by AutoCAD's Core Console (no window) with full AutoCAD 2013+, or by the built-in renderer without AutoCAD
  • Same scale, pages and bookmarks either way; print at Actual size / 100 %

Sheet list that flags what to check

  • Each output's CSV: village, survey number, named view, scale and paper
  • Sheets that were cropped, rotated or moved are flagged, so you check only those pages

Setup: ODA File Converter, Nudi fonts, AutoCAD

  • Status lights for the built-in engine, ODA File Converter, Nudi fonts and AutoCAD, each with a fix button
  • Installs the Nudi fonts for all users with one admin prompt, so Kannada text prints correctly in the AutoCAD PDF
  • Python 3.13, ezdxf and PyMuPDF built in; nothing else to install

How to draw the JMC sketch

  • Model space, in metres; each sheet a closed rectangle border with a “… JMC Sketch” title
  • The land-acquisition portion drawn as a hatch; the JMC table inside the border
  • The app's How to draw page also explains doing one sheet by hand and troubleshooting

Tested on a real 30-sheet village

  • Option D with the built-in renderer (no AutoCAD): all pages made
  • Option E at 1:1000 with AutoCAD 2022: 22 A3 and 8 A2 sheets, Kannada text correct

Your drawings are never changed. Results go into new “Option X” folders. Check the flagged sheets before printing.

FAQ

JMC sketch to PDF questions

What do I need to install for JMC Sheet Maker?

Only two things: ODA File Converter (free, from opendesign.com) to read the DWGs, and the Nudi fonts installed for all users. Python 3.13, ezdxf and PyMuPDF are built into the exe and unpack on first start (about 3 seconds). AutoCAD is optional. The Setup page shows a status light for each item, with a button to fix it.

Why does Kannada text print garbled in the PDF?

Usually the Nudi fonts are installed only for one Windows user, so AutoCAD and other programs cannot find them when they plot. On the Setup page, Install for all users copies the Nudi fonts into C:\Windows\Fonts with one administrator prompt, and the Kannada text then prints correctly.

Do I need AutoCAD to make the JMC sketch PDFs?

No. With full AutoCAD 2013 or newer, the PDFs are plotted by AutoCAD itself through its Core Console (no window opens), for the closest match to an AutoCAD print. Without AutoCAD, or with AutoCAD LT, the built-in renderer makes the PDFs at the same scale, with the same pages and bookmarks. The DWGs can be drawn in any CAD that saves AutoCAD .dwg files.

What scale are the sheets made at?

Option D puts every sheet at 1:1000 on A3, choosing portrait or landscape per sheet so the hatched land-acquisition portion fits best. Option E uses one scale you type as metres per cm on paper (10 = 1:1000, 5 = 1:500, 20 = 1:2000) and picks A3, A2, A1 or A0 per sheet so the whole sketch fits. Old notes such as “1 Cm = 16 Mtr” are corrected to the real scale. Print the PDFs at Actual size / 100 %, never Fit to page.

Are my DWG files changed?

No. Your DWGs are only read. The sheet DWGs, the PDFs and the sheet list are written into new “Option X” folders next to them; if a folder already exists, a new one such as “Option D (2)” is made, so nothing is overwritten.

How must the JMC sketch sheets be drawn?

In Model space, in metres (survey coordinates). Each sheet needs a closed rectangle polyline as its border, a title inside it containing “JMC Sketch” (the survey number is read from it), and the land-acquisition portion drawn as a hatch. A sheet without a closed rectangle border or a “JMC Sketch” title is skipped, so compare the sheet count in the log. The How to draw page in the app lists every rule.

Install

Download & run

JMC Sheet Maker is a single .exe that uses the .NET Framework 4 built into Windows 10 and 11. There's no installer: Python, ezdxf and PyMuPDF unpack to %LOCALAPPDATA% on first start (about 3 seconds). ODA File Converter is not bundled for licence reasons; get it free from opendesign.com.

  1. 1

    Download

    Click Download for Windows (51.5 MB). If your browser flags the new file, choose Keep.

  2. 2

    Open it

    The app is unsigned, so on “Windows protected your PC” click More info → Run anyway. Then follow the Setup page: ODA File Converter and the Nudi fonts.

  3. 3

    Try the sample

    Press Sample to write two made-up villages, then Make sheets to see the PDFs and the sheet list.
